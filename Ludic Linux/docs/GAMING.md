# Gaming on Ludic

## Steam

Steam comes from the Bazzite base image. Sign in to your Steam account and enable Steam Play for titles that need Proton. Start with the compatibility setting recommended by Steam; try another Proton version only when a game needs it.

## Epic, GOG, and Amazon

Heroic Games Launcher is supplied as a Flathub app. Open it from the app launcher and connect the stores you use. You still need to own each game and sign in with its publisher account.

## Proton versions

ProtonUp-Qt is included for people who need a community Proton or Wine build. Most games should start with the versions provided by Steam or their launcher. A custom build is a troubleshooting option, not a system-wide performance toggle.

## Controllers and displays

KDE Plasma supports a normal keyboard-and-mouse desktop, and common USB and Bluetooth gamepads can be paired from System Settings. Display refresh rate, HDR, VRR, and multi-monitor behavior depend on the graphics driver, monitor, cable, and game.

## Multiplayer and anti-cheat

Some games work well, some need adjustments, and some publishers block Linux clients. Before buying or switching your main machine, check current reports for the exact title and launcher. A system update cannot override a publisher-side block.
